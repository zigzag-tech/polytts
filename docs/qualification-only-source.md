# Qualification-only source boundary

This source does not activate a provider. Original services and accepted work stay
untouched. A separately registered, source/config-bound qualification unit must
have real canonical permission, recognized host capacity and an active node kind
lease before any model load. Unmanaged original contender bounds remain required.

Qualification source closes legacy inference, voice/model control, public warm/lease
and WebSocket ingress. `/health` is a static non-GPU read. Only owned job submission,
capabilities and existing owner-token status/cancel/audio controls remain reachable.
Temporary fence release does not open legacy inference. Accepted controls keep their
original authorization and remain usable after canonical grant expiry.

`POST /tts/jobs` requires the separate
`X-Provider-Qualification-Authorization: Bearer zzops_...` credential when qualification
mode is selected. The job control token cannot authorize new model work. Exact old
request hashing precedes prepare; the physical tracked worker enters the actual
node gate before `manager.ensure`. English and engine `voxcpm` must be explicit.
Unconfigured qualification bootstrap refuses. Absent qualification mode preserves
original behavior and original startup; new framework modules are not imported by
normal bootstrap.

## Offline canonical input digest

From this exact owner source:

```sh
python -I -B synthesis_input.py < qualification-model-input.json
```

The file contains only `{"request":{...},"voice_mode":"native"}` (or `registered`).
Output is `{"provider":"polytts","inputDigest":"..."}`. The standard-library-only
helper preserves original sorted compact Python JSON with ASCII Unicode escaping.
It imports no model, prepares no voice and grants no permission. Whole control
submissions, extra top-level fields, invalid voice modes and oversized input refuse
without echoing input. This digest differs from the consumer's managed control
`requestDigest`; neither may be relabeled as the other.

CPU source checks cover actual ASGI/owned-job execution with mocked canonical gate,
exact digest order, anonymous/forged/job-token refusal, accepted results after
revocation, isolated CLI Unicode/order controls and retained original startup.
They do not qualify real operator registration, full server imports, models,
GPU capacity, cancellation on a real backend or installed source/wheel/seal tuple.
