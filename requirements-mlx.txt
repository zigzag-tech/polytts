# hard `from livestack_node import ManagedUnit, ResidencyPolicy` — that is the
# whole point of the MLX path (polytts registers its Metal footprint so a host
# broker can evict voxcpm under pressure). It is a private package installed

# so it cannot go in this file: a git+ssh line would make `uv run ./run.sh` fail
# for anyone without repo access, which is worse than the honest gap.
#
# Consequence to know about: an MLX host without it starts, imports, and dies at
# server.py — repeatedly. See the crash-budget note in README's auto-start
# section before assuming a supervisor will bound that.
